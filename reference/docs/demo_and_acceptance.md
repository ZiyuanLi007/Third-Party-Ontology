# 演示与验收

1. 打开报告说明来源、版本、虚构范围和未审核标记。
2. A：查看同一监管义务对应的政策、步骤、控制及每一跳证据；两个要素均有文档支撑。
3. B：控制描述未注明签约前，结果 PARTIAL_SUPPORT，而不是确认不合规。
4. C：本次没有控制文件，结果 MATERIAL_MISSING；请 SME 判断缺文件还是缺控制。
5. D：控制明确为签约后，结果 CONFLICT；对照政策/程序中的签约前。
6. 运行测试删除 A 最后一条关系：材料仍在，结果 LINK_NOT_FOUND，区别于 C。
7. 查看原文、plain English 和 bank interpretation 三者的区别。

验收：所有证据可回到 sources 文件和 locator；TTL 可解析；SHACL 通过；四场景符合预期；断链不输出 compliance gap；review 不冒充真实 SME 审批；报告明确不评价运行有效性。

SME 核实表：选定法规版本/适用日期、法人范围、选定段落、上下文依赖、银行材料清单、控制定义或执行记录、每条映射理由、要素标签、报告展示粒度、扩样数量。可在 mappings.json 中记录确认状态；本版不提供审批界面。
